# gnaroshi-content-feed

Public generated content projection consumed by `Gnaroshi/gnaroshi.github.io`.

This repository contains generated publishable output only. Canonical paper research and writing remain in private repositories and must never be copied here directly.

`manifest.json` records the Paper Lab and Writing source commit SHAs, content hash, generator, counts, and projection timestamp. Every update must be generated by `gnaroshi-studio`, pass its privacy and deterministic-output validation, and be committed as one feed transaction.

Do not edit blog, paper, data, asset, or manifest output manually. Imported seed, demo, draft, hidden, private-note, transcript, and local-path data are forbidden from this public repository.
