# gnaroshi-content-feed

Public generated content projection consumed by `Gnaroshi/gnaroshi.github.io`.

This repository contains publishable output only. Canonical paper research and writing remain in private repositories. The initial migration snapshot is intentionally empty because imported sample and seed records have not passed publication review.

`manifest.json` records the source checkpoint and projection state. Future updates must be generated by the studio publisher, validated, and committed without secrets or private source metadata.
